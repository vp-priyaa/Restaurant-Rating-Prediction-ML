# Restaurant Rating Prediction System

## Cognifyz Technologies Machine Learning Internship

### Project Objective
Build a machine learning model to predict restaurant aggregate ratings using restaurant-related features.

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## Machine Learning Models
1. Linear Regression
2. Random Forest Regressor

---

## Model Performance

### Linear Regression
- R² Score: 0.25

### Random Forest Regressor
- R² Score: 0.95

---

## Key Insights
- Votes were the most influential feature affecting restaurant ratings.
- Restaurants with higher engagement generally had higher ratings.
- Random Forest performed significantly better than Linear Regression.

---

## Conclusion
The Random Forest Regressor achieved excellent prediction accuracy and proved effective for restaurant rating prediction tasks.
