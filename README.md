#  Restaurant Rating Prediction System

##  Project Overview

This project was developed as part of the Cognifyz Technologies Machine Learning Internship.

The objective of this project is to build a Machine Learning model capable of predicting restaurant aggregate ratings based on restaurant-related features such as votes, price range, location, and average cost.

The project demonstrates a complete end-to-end Machine Learning workflow including:

- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Regression Modeling
- Model Evaluation
- Feature Importance Analysis

#  Machine Learning Workflow

## 1. Data Preprocessing
- Handled missing values
- Selected important numerical features
- Prepared training and testing datasets

## 2. Exploratory Data Analysis
- Correlation heatmap
- Rating distribution analysis
- City-wise restaurant analysis

## 3. Model Building
Models Used:
- Linear Regression
- Random Forest Regressor

## 4. Model Evaluation
Evaluation Metrics:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

---

#  Model Performance

## Linear Regression
- R² Score: 0.25

## Random Forest Regressor
- R² Score: 0.95

The Random Forest model significantly outperformed Linear Regression and achieved excellent prediction accuracy.

---

#  Key Insights

- Votes were the most influential feature affecting restaurant ratings.
- Restaurants with higher engagement generally had better ratings.
- Price range showed moderate impact on ratings.
- Random Forest provided highly accurate predictions.
